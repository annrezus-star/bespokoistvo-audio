# Беспокойство — отдельный компонент карты

В этой папке только компонент настоящей векторной карты: **MapLibre GL JS 5.6.1 + OpenFreeMap / OpenStreetMap**, восемь точек 01–08, выделение, компактная подсказка, масштаб, перемещение, «Весь маршрут». Нет шапки, списка, аудиоплеера, геолокации и экскурсионных текстов. Старый прототип в `prototype/` и его опубликованная страница не изменены.

## Открыть

Для разработки:

```sh
cd map-component
python3 -m http.server 8081
```

Откройте `http://localhost:8081/map-demo.html`. Нужен интернет к **tiles.openfreemap.org** — оттуда поступают настоящие векторные тайлы, шрифты и значки. API-ключ, регистрация и сборка не требуются. SDK включён в `vendor`, версия зафиксирована; не подключается «latest» библиотеки.

Демонстрация занимает доступную область окна. Сам компонент зависит от размеров своего контейнера, а не страницы, и поддерживает несколько экземпляров. Для компонентов на Тильде рекомендуемая минимальная высота — 320 px.

## Почему MapLibre, а не Яндекс v3

Проверено в официальном npm-пакете `@yandex/ymaps3-types` версии **1.0.21703254**:

- `YMapDefaultSchemeLayerProps.customization` действительно существует: это официальный способ стилизации, без CSS-фильтра карты.
- Пешеходная маршрутизация — отдельный вызов `route({points, type: 'walking'})`, не часть показа подложки. В официальных типах отдельно есть `driving`, `truck`, `walking`, `transit`.
- Для запуска JavaScript API v3 нужен собственный ключ «JavaScript API и HTTP Геокодер», который получают в кабинете разработчика Яндекс Карт; тип продукта и доступность v3 нужно проверить в действующем кабинете. В среде ключа и соответствующих bindings нет.
- Условия применения Яндекс API внутри аудиогида после покупки **не подтверждены**: официальная страница условий и документация недоступны из среды (403). Бесплатность такого применения не заявляется. Возможности и квоты маршрутизации требуют отдельного подтверждения в договоре/тарифе.

Источники для проверки владельцем проекта: https://yandex.ru/maps-api/docs/js-api/ и https://yandex.ru/legal/maps_api/ . Для перехода на Яндекс нужны ваш собственный ключ с ограничением доменов и подтверждение условий платного аудиогида. Сейчас в файлах нет ни чужого ключа, ни неработающего Яндекс-плейсхолдера: выбран конкретный вариант без ключа и без подключения платного сервиса.

## Внешний интерфейс

Сначала загрузите `vendor/maplibre-gl.js`, `stops.js`, затем `map.js`. После этого:

```js
const widget = BespokoistvoMap.create(document.getElementById('my-map'), {
  stops: BespokoistvoStops,
  onStopSelect(id) {
    // Уведомление существующего аудиогида. Сам компонент звук не запускает.
  }
});

widget.ready.then(() => {
  // Подложка: в видимой области действительно отрисованы
  // векторные улицы / здания, а не просто создан canvas.
}).catch(error => {
  // Ошибка уже выведена в блоке карты.
});
widget.selectStop('mosselprom');
widget.selectStop('mosselprom', {notify: false});
widget.fitRoute();
widget.destroy();
```

- `selectStop(id)` выделяет точку и показывает подсказку. Возвращает `false` для неизвестного id или удалённого компонента. При изменении выбора вызывает `onStopSelect(id)`; повтор того же выбора не создаёт повторного события. `{notify:false}` подавляет уведомление при внешней синхронизации.
- `fitRoute()` показывает все восемь объектов с отступами. Расстояние и время не рассчитываются. Можно передать `{animate:false}`.
- `onStopSelect(id)` — callback в options. Дополнительно на контейнере происходит всплывающее событие `bespokoistvo:stopselect`, `event.detail = {id, order, coordinates}`.
- `destroy()` идемпотентно удаляет карту, worker SDK, маркеры, подсказки, наблюдатель размеров, таймеры и DOM компонента. Содержимое контейнера, не созданное компонентом, не удаляется.
- `getStatus()` возвращает состояние подложки, selectedStop, route, zoom, center и destroyed. `ready` относится к первой попытке загрузки. После успешного повтора загрузки контейнер получает `bespokoistvo:mapready`, а `getStatus().basemap` становится `ready`.
- `cooperativeGestures:true` в options включает режим совместных жестов MapLibre, полезный для длинной страницы Тильды; по умолчанию в демонстрации карта управляется непосредственно.

Стили компонента и SDK загружаются внутрь **Shadow DOM**. Они не меняют соседние блоки Тильды; CSS компонента использует префикс `bspm-`. Глобальные стили есть только в минимальном demo-файле для его собственной страницы.

## Встраивание в Тильду

Разместите папку на HTTPS-хостинге. В T123 можно напрямую добавить контейнер и скрипты (адрес `YOUR-HOST.example` — заменяемый пример, не готовый хостинг):

```html
<div id="bsp-map" style="width:100%;height:65svh;min-height:360px"></div>
<script src="https://YOUR-HOST.example/map-component/vendor/maplibre-gl.js"></script>
<script src="https://YOUR-HOST.example/map-component/stops.js"></script>
<script src="https://YOUR-HOST.example/map-component/map.js"></script>
<script>
  window.bspMap = BespokoistvoMap.create(document.getElementById('bsp-map'), {
    stops: BespokoistvoStops,
    cooperativeGestures: true,
    onStopSelect(id) { /* Здесь синхронизация с вашим интерфейсом. */ }
  });
  bspMap.ready.catch(() => {});
</script>
```

Для прямой интеграции хостинг должен отдавать `style.json` с CORS-доступом с вашего домена Тильды, корректными MIME JSON/JS/CSS; разрешите CORS и для файлов стилей в Shadow DOM при необходимости политики сайта. При Content Security Policy разрешите скрипты и стили вашего хостинга, `connect-src https://tiles.openfreemap.org`, WebGL и `worker-src blob:`. Никаких секретов в клиентский код не добавляйте.

Альтернатива без доступа родителя к API компонента — iframe с `map-demo.html`, `width:100%;height:65svh;min-height:360px;border:0`. В этом варианте JavaScript-интерфейс и события находятся **внутри iframe**; связь с родительским аудиогидом потребует отдельного адаптера postMessage с проверкой origin. Прямая интеграция выше сразу предоставляет нужный callback без такого адаптера.

## Данные, рисунки и маршрут

`stops.js` хранит исходные координаты **[долгота, широта]**. Порядок фиксирован. Неизвестные входы оставлены `approachCoordinates:null`. Остановки 02/03 и 05/06 разные; 08 — старое здание МГУ на Моховой. Для 07 явно показано предупреждение о неподтверждённом доступе во двор.

На малом масштабе близкие **номера** разводятся в пикселях, с тонкими оливковыми выносками и точкой на истинном положении объекта. Координаты не изменяются; выноски не являются маршрутом. Маркеры имеют область 44×44 px, управление доступно кнопками и с клавиатуры. Подсказка ограничена размерами контейнера.

Позднее добавьте проверенный SVG/PNG URL в `illustration`, подпись прав в `illustrationCredit`. У изображений отдельный слой и сдвиг от точки; их нет в текущей версии. Перед публикацией рисунков нужно проверить размещение относительно номеров и подписей на целевых масштабах.

**Пешеходная линия не добавлена.** OpenFreeMap не предоставляет маршрутизацию. Подтверждённой геометрии проходов и входов нет. Семь участков 01→02, 02→03, 03→04, 04→05, 05→06, 06→07 и 07→08 требуют проверки тротуаров, переходов и общедоступных подходов. Короткая ссылка https://yandex.com/maps/-/CXFjaT1j не проверена из среды из-за 403. Прямые или условные связи между остановками не рисуются. Никаких неподтверждённых расстояний, времени и обещаний прохода во двор нет.

## Стиль и проверка

`style.json` — модификация официального OpenFreeMap Liberty, с сохранёнными слоями улиц, зданий, парков, переходов и подписей. Точный upstream SHA записан в metadata. Цвета меняются через официальную спецификацию MapLibre Style Specification: fill/line/text paint, а не фильтр изображения карты. Библиотечный шрифт подложки — Noto Sans с кириллицей из OpenFreeMap; интерфейс — Arial/Helvetica, название в подсказке — Georgia. Навык bespokoistvo-colors в доступном каталоге отсутствовал; использована палитра из задания.

Проверка спецификации JSON-стиля прошла без ошибок. В Chromium проверены инициализация настоящего SDK/WebGL, восемь маркеров и исходные координаты, публичный API выбора и событие, камера/масштаб, обзор, размер 320 px, границы подсказки, ресайз, отсутствие горизонтального переполнения, размеры маркеров, отсутствие аудио и destroy. **Живая загрузка улиц и зданий в среде не подтверждена:** tiles.openfreemap.org возвращает 403 сетевого прокси. Это не заменялось фиктивными тайлами или схемой. При отсутствии подложки компонент показывает ошибку и скрывает номера на пустом фоне. Полностью готовой и проверенной живой картой результат до успешной загрузки тайлов не объявляется.

Проверка работы в опубликованной Тильде и полевое прохождение не выполнялись. Условия внешних источников рассмотрены по доступным официальным репозиториям 23 октября 2026 г.; отдельной юридической проверки лицензии платного продукта не проводилось.
