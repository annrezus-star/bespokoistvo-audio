# Беспокойство · Москва психологическая

Рабочий автономный прототип интерактивной схемы восьми остановок. Без сборки, внешних библиотек, регистрации, ключей и сервера приложения. Палитра и шрифты соответствуют заданию; навык `bespokoistvo-colors` в этой среде отсутствовал.

## Открыть

Распакуйте весь архив и откройте `index.html` в современном браузере. Рядом должны остаться CSS, JavaScript и папка `audio`.

Рекомендуемый и проверенный способ запуска — простой статический HTTP-сервер:

```sh
cd prototype
python3 -m http.server 8080
```

Откройте `http://localhost:8080`. Интернет нужен только для перехода в Яндекс Карты. Восемь оригинальных MP3 включены в комплект. Автозапуска звука нет. Звук на устройстве не оценивает громкость или безопасность окружающей обстановки.

`standalone.html` — полностью автономная версия одним файлом: CSS, JavaScript и все восемь MP3 встроены внутрь. Для воспроизведения интернет не нужен. Файл больше обычного HTML (около 9 МБ), потому что содержит аудио.

## Что работает

- Восемь остановок, список и карта синхронизированы, порядок 01–08 фиксирован.
- Выбор точки не меняет и не останавливает текущую аудиодорожку.
- «Открыть остановку» открывает окно с адресом, примечаниями и кнопкой «Слушать историю». Только эта кнопка явно выбирает и запускает историю.
- Постоянный плеер: воспроизведение/пауза, предыдущая и следующая дорожки, перемотка; на компьютере также отключение звука. Ошибки загрузки выводятся рядом с названием, повторная попытка — кнопкой воспроизведения. Следующая дорожка автоматически не запускается.
- «Идти сюда» открывает `https://yandex.ru/maps/?mode=routes&rtext=~LAT%2CLON&rtt=pd`: пешеходный режим с выбранным объектом в качестве назначения и без фиктивной стартовой позиции.
- Закрытие и сворачивание карточки, переход к следующей остановке, увеличение/уменьшение, обзор всего маршрута, перетаскивание мышью/пальцем. Перетаскивание не активирует маркер.
- Явная отметка «Пройдено». Сохранение в localStorage при наличии доступа; при запрете хранения состояние работает в памяти страницы. Просмотр точки не отмечает её пройденной.
- Мобильный переключатель «Карта / Остановки», сворачиваемая нижняя карточка, safe-area. Маркеры и основные элементы управления имеют область нажатия от 44 px. Номера некоторых соседних объектов вынесены; тонкая линия связывает номер с неизменённой исходной точкой.
- Управление с клавиатуры, подписи кнопок, модальное окно с возвратом фокуса. Геолокация не запрашивается.

## Данные и обновления

- `data.js`: стабильные id, исходные lat/lon WGS84, order, полные и краткие названия, адреса, отдельные `approachCoordinates`, `image`, `imageCredit`, `audioUrl`. Неизвестные подходы и изображения оставлены `null`.
- `route.js`: семь участков с `from`, `to`, `status`, `coordinates`. Во всех статус `unverified`, `coordinates: null`.
- `styles.css`: все основные классы и переменные с префиксом `bsp-`; Arial/Helvetica для интерфейса и Georgia для заголовков остановок.
- `app.js`: проекция Web Mercator, отрисовка, взаимодействия, сохранение прогресса и плеер.
- `index.html`: оболочка. `audio/01.mp3`–`08.mp3`: оригинальные дорожки из корня репозитория.

В `approachCoordinates` и геометрии `coordinates` используется порядок **[долгота, широта]**, в полях объекта — отдельные `lat`, `lon`. Координаты объекта никогда не подменяются координатами выносного номера или подхода. При добавлении фотографии укажите проверенный источник и права в `imageCredit` — карточка подробностей покажет фото и подпись.

Если вы подтвердите путь, внесите реальную линию [lon,lat] в участок и измените его статус на `verified`. В текущей версии оформление всей линии намеренно пунктирное, общий статус карты и предупреждения нужно пересмотреть перед публикацией проверенной навигационной версии.

## Встроить в Тильду

1. Разместите папку `prototype` на любом собственном HTTPS-хостинге статических файлов. Сохраните относительные пути; для MP3 нужен MIME `audio/mpeg`, желательно HTTP Range для перемотки. Бесплатные статические хостинги подойдут. Опубликованные страницы Тильды в рамках работы не изменялись.
2. В блок HTML T123 вставьте содержимое `tilda-embed.html`, заменив `YOUR-DOMAIN.example` на фактический адрес папки. `iframe` изолирует стили и фиксированный плеер от страницы Тильды.
3. Проверьте высоту блока на реальном телефоне. Не помещайте iframe внутрь контейнера с фиксированной маленькой высотой или `overflow:hidden`. Настройки хостинга должны разрешать встраивание на вашем домене (`frame-ancestors` / X-Frame-Options).
4. Не вставляйте сырые MP3 или весь исходный код в визуальный текстовый блок. Для варианта «один HTML» можно разместить `standalone.html`: дополнительные файлы и доступ к GitHub для аудио не требуются.

При открытии подробностей приложение вызывает событие:

```js
window.addEventListener('bespokoistvo:open-stop', event => {
  console.log(event.detail.id, event.detail.order);
});
```

Событие происходит внутри страницы прототипа/iframe. Оно информационное: «Открыть остановку» уже имеет рабочую реализацию и не зависит от callback. Для связи с родительской Тильдой потребовался бы отдельный согласованный адаптер postMessage.

## География, источники и ограничения

**Это схема маршрута, не точная пешеходная навигация.** Пунктирные кривые означают только последовательность объектов, а не путь по улицам. Здесь нет нарисованных или скопированных зданий, кварталов, входов, переходов или парков. Подписи улиц — приблизительные ориентиры из предоставленных адресов, не картографическая геометрия улиц. Схематические кривые нельзя использовать для определения прохода через здания и дворы.

Все координаты объектов и адреса — из задания автора. Проекция Web Mercator, север сверху. Расстояния и время переходов не рассчитывались и не показываются. Проверенных входов нет. Особое предупреждение о дворе Психологического института показано в карточке и подробностях.

Все семь участков требуют полевой или картографической проверки:

| Участок | Что проверить |
| --- | --- |
| 01 → 02 | Тротуары, переходы и подход к Дому Гоголя / сидящему памятнику Андреева |
| 02 → 03 | Путь к отдельному стоящему памятнику Томского, переходы у Арбатской площади |
| 03 → 04 | Обратный путь к Калашному переулку, переходы и подход к Моссельпрому |
| 04 → 05 | Выход к Воздвиженке и подход к особняку Арсения Морозова |
| 05 → 06 | Два разных объекта; доступные места остановки у каждого |
| 06 → 07 | Тротуары и переходы до Моховой; доступ во двор института не подтверждён |
| 07 → 08 | Путь по общедоступной улице к старому зданию МГУ на Моховой |

23 октября 2026 г. источники `https://yandex.com/maps/-/CXFjaT1j`, обе страницы `feel-virtual-lynx.tilda.ws/moscow-guide-layers` и `/moscow-guide-visual`, а также Overpass (`overpass-api.de`) вернули 403 из среды разработки. Поэтому короткая ссылка **не проверена** на восемь точек и режим. Геометрия OSM не получена и в комплект не входит; скриншоты Яндекс Карт не использовались. Фотографий и контурных иллюстраций нет: используются честные номера и подписи. Архив по годам и сравнение фотографий не добавлялись из-за отсутствия материалов.

Аудио: файлы `01.mp3`–`08.mp3` репозитория `annrezus-star/bespokoistvo-audio`, также доступны по URL `https://raw.githubusercontent.com/annrezus-star/bespokoistvo-audio/main/01.mp3` (номер меняется). Права на исходные материалы остаются у их правообладателей. Внешних JS/CSS-зависимостей, сторонних картографических данных и платных сервисов нет.

## Проверка

В Chromium проверены компьютер 1440×1040 и телефон 390×844: восемь точек и подсветка; карточка/закрытие/раскрытие/подробности; масштаб и обзор; переход к следующей; URL внешней навигации; воспроизведение реального MP3 и независимость аудио от выбора точки; персистентность прогресса после перезагрузки и работа при запрете localStorage; обработка ошибки аудио; различие drag/click; область маркера 44 px; отсутствие горизонтального переполнения и перекрытия карточки плеером. Необработанных ошибок JavaScript нет. Все восемь исходных MP3 ранее полностью декодированы FFmpeg без ошибок.

Индекс и версия одним файлом проверены по HTTP. Встроенная аудиодорожка версии одним файлом воспроизводится без сети; прямое обращение к GitHub в предварительном варианте не загрузило метаданные за 30 секунд, и зависимость от него устранена. Прямая проверка `file://` заблокирована политикой управляемого браузера среды (`ERR_BLOCKED_BY_ADMINISTRATOR`), это не ошибка JavaScript приложения.

Построение пути на внешнем Яндексе, реальный проход на местности, работа внутри опубликованной Тильды, Safari/iOS и акустическое прослушивание не проверялись. Развёртывание и публикация не выполнялись.
