# Москва психологическая · карта v2

Только отдельный компонент карты. **MapLibre GL JS 5.6.1 + OpenFreeMap / OpenStreetMap**, без смены поставщика, новых ключей и платных услуг. Исходная версия `map-component/` и ветка `bespokoistvo-preview` сохранены; эта копия — `map-component-v2/`, ветка `bespokoistvo-map-v2`.

## Что изменилось

- Начальная камера рассчитывается по границам восьми исходных координат уже в конструкторе SDK, без фиксированного стартового масштаба. «Весь маршрут» закрывает карточку и возвращает исходное кадрирование. Размер контейнера, кнопки и нижняя атрибуция учитываются; на ресайзе обзор пересчитывается, а при выбранной точке сохраняется масштаб.
- При выборе показывается компактная нижняя карточка: номер, название и адрес. Карта только плавно смещается, если выбранный номер или истинная точка попали под карточку; масштаб не меняется. Высота атрибуции измеряется, поэтому карточка остаётся выше неё.
- Обычный кружок 34 px, выбранный розовый — 40 px. Область нажатия обоих 44×44 px. Близкие номера разводятся на экране с тонкими оливковыми выносками к настоящим координатам. Для 05/06 сохранено направление: 06 южнее и восточнее 05.
- Из JSON-стиля убраны коммерческие POI, наземный транспорт, цветные транспортные значки, автомобильные стрелки и дорожные щиты. Сохранены названия улиц и переулков, культурные ориентиры, парки, вода и подписи метро. Метро отображается спокойной подписью «М · название» по данным поставщика. Здания и второстепенные дороги менее контрастны; здания остаются видимыми на крупном масштабе как плоские контуры.
- CSS изолирован Shadow DOM. Высота задаётся контейнером. Совместные жесты включены по умолчанию: обычная прокрутка страницы сохраняется, карта на телефоне перемещается двумя пальцами; для колеса требуется Ctrl/⌘. Кнопки масштаба работают непосредственно.

Авторских рисунков нет: достоверных материалов не предоставлено. В данных сохранены поля `illustration` и `illustrationCredit`; будущие изображения автоматически скрываются при ширине менее 600 px или масштабе менее 16.

## Открыть

Веб-демонстрация:

https://raw.githack.com/annrezus-star/bespokoistvo-audio/bespokoistvo-map-v2/map-component-v2/map-demo.html

Локально — из этой папки:

```sh
python3 -m http.server 8082
```

Откройте `http://localhost:8082/map-demo.html`. Нужен доступ к `tiles.openfreemap.org` для настоящих векторных тайлов, шрифтов и значков. При отказе источника показывается ошибка, а не фиктивная подложка. SDK поставляется в `vendor/`, API-ключ не нужен.

## Вставить в Тильду

Самый короткий способ: блок HTML T123, внутри — iframe демонстрации с высотой, заданной внешней страницей:

```html
<iframe
  src="https://raw.githack.com/annrezus-star/bespokoistvo-audio/bespokoistvo-map-v2/map-component-v2/map-demo.html"
  title="Москва психологическая — карта прогулки"
  style="display:block;width:100%;height:560px;border:0"
  loading="lazy"
></iframe>
```

Для постоянной эксплуатации предпочтителен собственный HTTPS-хостинг папки. Измените `src` на свой адрес. Высоту 560 px можно заменить нужной; рекомендуемая минимальная высота — 360 px. Компонент не требует 100vh: полноэкранная высота есть только в демонстрационном HTML.

Для прямой связи с существующим аудиогидом подключите `vendor/maplibre-gl.js`, `stops.js`, `map.js`, создайте контейнер с заданной высотой и вызовите:

```js
const widget = BespokoistvoMap.create(document.getElementById('your-map'), {
  stops: BespokoistvoStops,
  onStopSelect(id) { /* Обработчик аудиогида; карта сама звук не запускает. */ }
});
widget.ready.catch(() => {}); // Ошибка уже выводится в блоке карты.
widget.selectStop('mosselprom');
widget.fitRoute();
widget.destroy();
```

`selectStop(id, {notify:false})` подавляет обратное событие при синхронизации. Выбор меняет только выделение и карточку. `fitRoute({animate:false})` даёт обзор без анимации; `{keepCard:true}` сохраняет карточку и учитывает её при вписывании. Callback вызывается при изменении выбора; дополнительно контейнер получает событие `bespokoistvo:stopselect` с `{id, order, coordinates}`. `destroy()` идемпотентно отключает наблюдатели размеров, таймеры, SDK и созданный DOM. Нет геолокации и аудио.

В iframe эти API и события находятся внутри фрейма. Для связи с родительским аудиогидом используйте прямое подключение либо отдельный postMessage-адаптер с проверкой origin. При прямой загрузке с другого домена разрешите CORS для `style.json` и CSS. Для CSP нужны разрешения хостинга ресурсов, `connect-src https://tiles.openfreemap.org` и `worker-src blob:`.

## Пешеходная линия

**Пока отсутствует.** Достоверная геометрия в проекте не найдена. 24 октября 2026 г. запрос к бесплатному FOSSGIS `routing.openstreetmap.de/routed-foot` с профилем `foot` и всеми восемью точками вернул 403 сетевого прокси; ссылка Яндекс также недоступна. Автомобильная маршрутизация и декоративные соединения не использовались. OpenFreeMap сам маршруты не строит.

Для добавления нужны полученная пешеходным маршрутизатором или проверенная на местности линия в формате GeoJSON [долгота, широта], переходы в порядке 01→08 и отдельная проверка общедоступного подхода к 07. Доступ во двор института не обещается. `route-status.json` фиксирует семь непроверенных участков; во всех `coordinates:null`. Расстояние и время не показываются.

## Данные, условия и проверка

`stops.js` — восемь исходных объектов WGS84, порядок [долгота, широта], стабильные id и адреса; подходы неизвестны (`approachCoordinates:null`). Координаты не сдвигаются. `style.json` — изменение официального Liberty через MapLibre Style Specification, без CSS-фильтров и вымышленных улиц. Источник стиля и upstream SHA сохранены в metadata, лицензии — в `licenses/`.

OpenFreeMap по официальному README бесплатен, без регистрации, ключей и лимитов запросов, но без гарантированного SLA: https://github.com/hyperknot/openfreemap#readme . Атрибуция OpenFreeMap, OpenMapTiles, © OpenStreetMap contributors и Liberty сохранена. Данные OSM распространяются по ODbL; коммерческое применение допускается с соблюдением её требований: https://www.openstreetmap.org/copyright . Лицензии компонентов: https://github.com/hyperknot/openfreemap/blob/main/LICENSE.md .

Проверены оригинальные координаты, JSON-стиль, начальные границы, выбор восьми точек, адреса, возврат к обзору, отсутствие зума при выборе, границы карточки и атрибуции, порядок 05/06, размер 320 px, область нажатия 44 px, масштаб и destroy. Живая загрузка подложки из среды пока не подтверждена: `tiles.openfreemap.org` возвращает 403. Тесты SDK и интерфейса не подменяют эту проверку; тестовые тайлы и фиктивная карта не применялись. Встраивание на опубликованную Тильду и полевое прохождение не проверялись.
